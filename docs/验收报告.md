验收对象为 `dist/` 的实际构建结果，并通过本地服务器在浏览器中加载；不是只检查源文件。

## 强制验收结果

1. **人物模式与透明度：通过。** 正好十张不同人物，全部 RGBA、1600×1600，背景 Alpha 最小值均为 0；各图最高 Alpha 与完整包围盒见原始数据表。
2. **透明边缘：通过。** 十张人物逐一叠放在深青色、棋盘格和白色背景上检查，未见白底、黑底或烘焙棋盘格；见 `00-人物透明边缘三底色检查.png`。
3. **人物完整与对齐：通过。** 非透明内容均在画布内，统一基线 y=1489，顶部与四周保留透明安全区。
4. **背景系统：通过。** 首页、结果页和十个详情页使用真实水彩插画；12 个实际页面的背景图片均加载成功，安静薄雾背景保留给无生日参数的结果提示状态。
5. **首页五行状态：通过。** 中心为“五种节奏 / 五行 / 木·火·土·金·水”的中性状态；没有“我的日主 / 丁火 / 点亮者 / 04/10”，五节点同尺寸且默认全部未选中。
6. **个性化结果：通过。** 表单真实提交 `2000-01-01` 得到戊土，提交 `2000-01-02` 得到己土；结果页标题、人物和详情返回链路同步变化。
7. **单次渲染：通过。** 所有检查页均只有一个 `main`，同名 `data-section` 无重复；构建中没有 React hydration、RSC 载荷或 MutationObserver DOM 补丁。
8. **正文保留：通过。** 对照 V4 的十篇详情页，280 段长度不少于 40 字的正文全部保留；关系、成长、长文模块没有用隐藏或删除处理布局。
9. **移动端与布局：通过。** 指定六个视口均无横向滚动、重复区块、失败图片或低于 48px 的主要按钮/日期控件。首页生日区按字段标题、日期输入、主按钮、辅助说明纵向分层，错误提示不会挤压或覆盖控件；移动端日主卡片为单列布局。
10. **五行地图手机尺寸：通过。** 360、390、430 宽度下五节点等大、全部位于地图容器内且默认未选中。
11. **控件状态：通过。** 实际指针事件记录到 hover=true 与按下时 active=true；点击火元素后只选中火并显示丙火、丁火入口；键盘聚焦显示 3px 可见描边。按钮 CSS 同时包含 default、hover、active、focus-visible；移动端主控件高度不低于 48px。
12. **功能链路：通过。** 首页日期输入、结果跳转、结果到详情、详情返回个人结果、首页导航、五行选择和身份卡生成均正常；结果页“回到首页”链接返回唯一测算入口。
13. **构建与浏览器日志：通过。** `npm run build` 生成 12 个单次渲染页面，自动检查通过；浏览器 error/warn 日志为空。旧 `/test` 地址会自动返回首页。
14. **V4 原件：通过。** `outputs/day-master-atlas-v4.zip` 保留，SHA-256 为 `56DAE005FE904AA51EFE105DB7D383406204887BDD38F6B281174939F2DF361F`。
