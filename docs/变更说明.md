# V5 变更说明

V5 在保留 V4 产品气质、十日主身份、长文内容、关系内容和日期计算规则的前提下，重新整理了页面与素材系统。

## 人物与氛围

- 十位水彩元素精灵全部改为用户最终指定总图中的对应造型，并分别完成高清化、水彩层次、轮廓收笔和表情细节升级。
- 乙木压低过曝与透明感，调整为橄榄绿、苔绿和克制玉石绿；己土盆中幼苗改为一朵小花，土层与颗粒改为柔和连续的水彩表达。
- 十张正式人物统一为 1600×1600 RGBA 透明 PNG，并完成边缘清理、统一视觉尺寸和脚底线对齐。
- 新增首页、无生日参数提示状态以及木、火、土、金、水五系共七张独立水彩背景；人物直接叠放在背景上，文字对比由独立遮罩控制。

## 首页与产品表达

- 首页公共模块改为平衡的“五行系统”，中心使用中性纸绿，不默认展示丁火或任何个人结果。
- 五个元素节点拥有一致尺寸、权重和 hover / active / focus / click 能力；选择后展示该元素的两种日主入口。
- 整体文案把“八字日主”放在产品中心，保留探索倾向、不预测命运的边界；原有解析正文没有大改或删减。

## 页面与功能

- 以统一模板重建首页、结果入口和十个详情页，移除 V4 的静态快照客户端、RSC、hydration 与延迟 DOM 补丁。
- 删除独立生日测算页，首页生日框成为唯一测算入口；旧 `/test` 地址自动返回首页，所有旧入口同步回到首页。
- 删除首页顶部重复的“查我的日主”、HOW 区“现在开始”和底部重复 CTA；生日字段统一显示“出生日期”。
- 重新整理移动端首页生日区：将“公历”改为轻量标识，统一输入框和按钮高度、圆角及间距，并为说明与错误提示建立独立分隔区域。
- 删除结果页的个人五行位置模块和“复制分享文案”，顶部不再显示“五行系统”；原“测测朋友”改为“回到首页”。
- 三层冲突样式合并为 `public/styles.css`；没有 `!important`，没有 brightness / contrast / multiply 人物补救滤镜。
- 统一背景、遮罩、人物、正文、弹窗层级；移动端卡片改为单列，表单自然堆叠，长中文按阅读宽度换行。
- 保留日期校验、日主计算、结果跳转、详情返回、五行选择、站内导航和身份卡生成。

## 验证

- 构建产生 12 个页面；十个日主结果与正文数据均有自动检查。
- 首页、结果页和十个详情页在本地构建中实际加载通过；旧 `/test` 重定向到首页。
- 六个指定视口和 360 / 390 / 430 三种五行地图宽度均完成浏览器检查。
