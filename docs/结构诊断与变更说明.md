# V5 整理记录

## V4 实查结果

- V4 以下载的 HTML 快照为页面，仍加载原 Vinext / React 模块和内嵌 RSC 数据；另有 `atlas-v4.js` 在延迟后通过 MutationObserver 改写同一 DOM。
- 原样式、local-overrides.css、atlas-v4.css 同时存在，含多组互相覆盖的显示、尺寸、绝对定位和媒体查询。
- 首页公共五行中心和主视觉直接写有丁火、点亮者、04 / 10。
- 浏览器复查 V4 记录到 `[vinext] RSC prefetch setup error: TypeError: ee is not a function`。此次首页初次加载与一个结果页未复现多个 main；不将未复现的具体触发路径写成已确认事实。
- 新结构移除静态快照与客户端 hydration 共管页面的机制、全部 RSC 载荷、原打包客户端、MutationObserver 和 V4 覆盖样式；不再修补既有 DOM。

## V5 结构

- `src/profiles.json`：完整十日主数据，含原有深度正文。
- `src/readings.json`：从 V4 保留的九个正文段落模块，每个详情页各出现一次。
- `src/render.mjs`：统一页面模板、五行地图、表单、人物和分享结构。
- `public/styles.css`：唯一展示样式，统一控件、图层和断点，无 !important，无人物提亮/对比度/混合补救。
- `public/app.js`：日期校验、个人结果的单次渲染、五行选择、返回和身份卡。
- `src/daymaster.mjs`：原日期算法，支持区间、闰年校验、儒略日基准和换日规则保持一致。
- `build.mjs`：生成首页、结果入口和十个详情页。生日测算只在首页，结果入口无默认个人结果。
- `server.mjs`：运行本地构建结果，不依赖原站 RSC 服务。

生日提交使用浏览器 URL fragment（#birthday=），不发送给本地服务器；原 `?birthday=` 入口仍兼容。首页不读取个人日主，并清除返回状态。
