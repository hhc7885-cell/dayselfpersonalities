# 日主图鉴 V5

这是基于 V4 独立整理的 V5 源工程与可运行页面。原 V4 ZIP 未修改、未删除。

## 本地使用

安装 Node.js 后，在此目录打开终端：

1. `npm run build`
2. `npm run dev`
3. 打开 http://localhost:4175

无需下载任何额外运行依赖。`dist/` 内附本次验收的构建页面；可以直接运行 `npm run dev` 查看。

## 文件入口

- `src/`：完整日主数据、正文模块、统一页面模板、原生日算法。
- `public/characters/`：最终十位独立透明人物。
- `public/backgrounds/`：首页、生日、五种元素背景。
- `public/styles.css`：唯一展示样式。
- `public/app.js`：原有功能的独立实现。
- `docs/`：变更说明、素材清单、验收报告和截图。

## 保留与变化

十位人物身份、原有解析正文、关系内容和日主算法均以 V4 为基准。首页五行模块没有默认个人结果，结果页仅在有效生日后显示真实日主。旧 URL 的 `?birthday=` 方式仍兼容；新版提交改为 `#birthday=`，生日在浏览器中计算。生日测算入口只保留在首页，访问旧 `/test` 地址会自动返回首页。

本版移除了旧快照客户端、RSC、延迟 DOM 补丁与互相覆盖的样式。页面内容按统一模板构建，长文内容没有为了排版而截断或隐藏。

图片和验收详情见 docs 内相应文件。
